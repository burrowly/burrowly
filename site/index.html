Map how your machines talk. Dig down to every wire.

Burrowly turns plain YAML files into clickable architecture diagrams for robots, machines and plants. Start at the whole system, double-click into any block, and see exactly what every connection carries: protocol, data format, timing and owner.

Your architecture lives in five places. None of them agree.

The block diagram is in Visio, the interface list is in a spreadsheet, the timing is in someone's head, and all three drifted apart months ago.

One source of truth

Every diagram level is a small YAML file in git. Review changes in a pull request like any other code.

Interfaces, not just boxes

Each line knows its protocol, data format, timing and owner. The interface table shows what is still missing.

Levels that stay in sync

Checks warn when a connection exists one level up but is not drawn inside the subsystem.

No lock-in

Plain text, one HTML file, no database and no account. Run it with Node or Docker on your own machine.

How it works

Drill down as deep as you need

Any block can open into its own diagram: system, robot, computer, board. External blocks show how lines leave each level, and the breadcrumb takes you back up.

Trace data end to end

A data stream follows data through blocks on every level, like a lidar scan travelling from a robot's nose to the operator's tablet. Burrowly adds up the latency of each step and exports the overview to PDF, Excel or CSV.

Edit without writing YAML

Drag a block onto the diagram, drag its + onto another block to connect them, and fill in the details. Burrowly writes the YAML for you and keeps your comments, so git diff shows exactly what changed.

Meet Molehill Works

The demo is a made-up system: a small fleet of digging robots builds tunnels under a field, run from an underground HQ. It is three levels deep.

  • 1Molehill Works: Burrow HQ, two diggers, a soil conveyor, a charging den, a tunnel sensor mesh and the foreman's tablet.
  • 2Digger Molly: the robot's main computer, tunnel radio, safety controller, whiskers, claw tracks, battery and spoil hatch.
  • 3Drill Head: the cutter motor and its driver, a microcontroller, the snout lidar, a torque sensor and a soil hardness probe.

Four data streams run through it, including the foreman's stop button: 107 ms from tablet to cutter motor, across all three levels.

Get started in a minute

You need Node.js 18 or newer, or Docker. There is nothing to install from npm.

git clone https://github.com/burrowly/burrowly.git
cd burrowly
node tools/serve.mjs --model examples/molehill-works   # open http://localhost:4321

# or with Docker, for your own model in ./model
docker compose up -d

Then read the YAML guide, or let GitHub Copilot draft the model from your notes.
