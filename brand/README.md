# Burrowly brand

| File | Use |
|---|---|
| `burrowly-mark.svg` | The mole on its own: favicon, app icon, README |
| `burrowly-logo.svg` | Mole plus wordmark (the wordmark is set in Sora Bold) |
| `burrowly-avatar-500.png` | GitHub organization avatar |
| `burrowly-social-1280x640.png` | GitHub social preview (repo Settings, General, Social preview) |

## Colors

| Token | Light | Dark |
|---|---|---|
| Background | `#f4f4fa` | `#121120` |
| Surface | `#ffffff` | `#1a1930` |
| Text | `#1c1a3a` | `#ecebfa` |
| Lines | `#dad9ea` | `#302e4c` |
| Accent (indigo) | `#4b3fd1` | `#9b93ff` |
| Signal (sunflower) | `#f2b705` | `#ffd23f` |

## Type

- Headings and wordmark: **Sora** (600, 700)
- Interface: **Nunito Sans**
- Data, YAML and diagram labels: **Martian Mono**

All three are free (SIL Open Font License) on Google Fonts.
